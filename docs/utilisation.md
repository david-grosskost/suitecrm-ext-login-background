# Utilisation

## Ce qui change

La page de connexion affiche en fond l'image choisie par l'administrateur, recadrée pour
couvrir l'écran. Sans image, elle garde son fond habituel.

## Réglages

**Administration → Page de connexion → Fond de la page de connexion**, réservé aux
administrateurs :

- choisir une image **JPG, PNG ou WebP**, de **5 Mo au plus** (une image large, 1920 × 1080
  par exemple, rend le mieux), puis **Enregistrer** ;
- un aperçu montre l'image en place ;
- **Retirer l'image** rend le fond habituel.

Une nouvelle image s'affiche dès la prochaine ouverture de la page de connexion.

## Données de démo

Aucune.

## Limites

Une seule image, la même pour tous : pas d'image par utilisateur ni de diaporama.
